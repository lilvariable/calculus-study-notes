# Calculus Study Notes & Solutions

A personal learning project containing original, detailed worked solutions and explanations developed while studying calculus.

## Purpose

This repository has three goals:

- Rebuild and strengthen my understanding of calculus through deliberate problem-solving.
- Maintain an organized reference library for future study.
- Share original mathematical explanations that may help other learners.

## Textbook Reference

- **Title:** *Calculus: One and Several Variables*
- **Authors:** Robert Ellis and Denny Gulick
- **Edition:** Fourth edition
- **Publisher:** Harcourt College Publishers
- **Publication year:** 1991
- **ISBN-10:** 0155056921
- **ISBN-13:** 9780155056923

Chapter and section organization will follow the fourth edition used for this project.

## Repository Organization

- [`chapters/`](chapters/) — chapter-by-chapter notes and worked solutions.
- [`templates/solution-template.md`](templates/solution-template.md) — the standard format for documenting an exercise.

## Solution Format

Each documented exercise aims to include:

1. A textbook chapter, section, and exercise reference.
2. The mathematical concepts and techniques used.
3. A clear statement or concise description of the problem in my own words.
4. A detailed, step-by-step derivation with explanations.
5. A clearly identified final result.
6. A brief takeaway or verification when useful.

Mathematics is formatted with LaTeX in GitHub-flavored Markdown.

## Copyright and Attribution
