# Calculus Study Notes & Solutions

A growing collection of original, detailed worked solutions and mathematical explanations based on *Calculus: One and Several Variables* by Robert Ellis and Denny Gulick (4th edition).

## Purpose
- Rebuild and strengthen calculus understanding through independent problem-solving.
- Maintain an organized mathematical reference.
- Share clear explanations that may help other learners.

## Textbook reference
- **Title:** *Calculus: One and Several Variables*
- **Authors:** Robert Ellis and Denny Gulick
- **Edition:** Fourth edition

Exercise numbers are provided as references. This repository is intended for original solutions and explanations, not scans or reproductions of textbook pages or substantial copyrighted problem text.

## Organization
The `chapters/` directory follows the textbook's 16-chapter organization. Each chapter README lists its sections. Add solution files within the relevant chapter folder.

## Solution standards
Solutions should include a textbook exercise reference, concepts used, detailed steps with explanations, a clearly identified final answer, and a takeaway or verification when useful. Mathematical expressions use LaTeX in Markdown.

## Workflow
1. Attempt each exercise independently.
2. Review the work for mathematical accuracy.
3. Transcribe the solution into Markdown/LaTeX.
4. Save it in the appropriate chapter folder.
5. Commit and push changes to GitHub.

This is an ongoing learning project. Consult the textbook for its original exposition and exercises.
